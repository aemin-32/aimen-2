# دليل المهام (Missions) - الجزء الأول: الأساسيات والتصنيف 📋

هذا الدليل هو المرجع الشامل لنظام المهام (Task Protocol) في Ascension. المهام تختلف عن العادات بأنها "تُنجز مرة واحدة" (One-off) غالباً، وتمثل خطوات فعلية نحو أهدافك.

## 1. مفهوم المهمة (Mission)
المهمة هي أمر عملياتي يجب تنفيذه.
- **الفرق عن العادة:** العادة تتكرر للأبد (بناء هوية)، المهمة تنتهي (إنجاز هدف).
- **الفرق عن الغارة:** المهمة وحدة مفردة، الغارة سلسلة مهام مترابطة.

## 2. تصنيف المهام (Categorization)
يتم تنظيم المهام في "فئات" (Categories) لترتيب حياتك.
- **أمثلة للفئات:** `Work`, `Personal`, `Learning`, `Side Hustle`.
- **الطي والتوسيع:** يمكنك طي الفئات للتركيز على ما يهمك فقط.

## 3. مستويات الصعوبة (Difficulty)
مثل العادات، تحدد الصعوبة المكافأة.

| المستوى | الوصف | مثال |
| :--- | :--- | :--- |
| **Easy** | مهمة سريعة (5-15 دقيقة) | إرسال إيميل، ترتيب المكتب |
| **Normal** | مهمة قياسية (30-60 دقيقة) | كتابة تقرير، حضور اجتماع |
| **Hard** | مهمة عميقة (2+ ساعات) | برمجة ميزة كاملة، دراسة فصل كامل |

## 4. الإحصائيات (Stats)
كل مهمة تغذي إحصائية معينة.
- **STR:** مهام بدنية (نقل أثاث، تصليح).
- **INT:** مهام ذهنية (دراسة، قراءة).
- **DIS:** مهام مملة تتطلب انضباطاً (تنظيف، فواتير).
- **CRT:** مهام إبداعية (تصميم، كتابة).
- **FIN:** مهام مالية (ميزانية، استثمار).
- **REL:** مهام اجتماعية (اتصال بالعائلة، خروج مع أصدقاء).
- **SPR:** مهام روحية (تأمل طويل، خلوة).
- **HEA:** مهام صحية (طبخ وجبة صحية، موعد طبيب).
