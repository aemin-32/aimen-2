# دليل الأوسمة والإنجازات (Achievements) - الجزء الأول: الأساسيات 🏆

هذا الدليل مخصص لشرح نظام الأوسمة في Ascension، وهو الجزء الأول من سلسلة مكونة من 4 أجزاء.

## ما هي الأوسمة (Badges)؟
الأوسمة هي نظام تقديري يكافئك على تحقيق إنجازات معينة في حياتك الرقمية. تظهر الأوسمة في "قاعة المجد" (Hall of Fame) وتعكس مدى التزامك وتطورك.

## مستويات الأوسمة (Badge Tiers)
كل وسام في النظام يتكون من 4 مستويات متصاعدة، ولكل مستوى متطلباته ومكافآته الخاصة:

1.  **الفضي (Silver):** المستوى المبتدئ، يتطلب مجهوداً بسيطاً.
2.  **الذهبي (Gold):** المستوى المتوسط، يتطلب التزاماً مستمراً.
3.  **الماس (Diamond):** المستوى المتقدم، يتطلب إتقاناً حقيقياً.
4.  **القرمزي (Crimson):** المستوى الأسطوري، مخصص للنخبة فقط.

## هيكل الوسام (Badge Structure)
يتكون الوسام من العناصر التالية:
- **الاسم والأيقونة:** تعريف مرئي للوسام.
- **الفئة (Category):** (مثل: Progression, Combat, Warfare, Consistency).
- **نوع المحفز (Trigger Type):** الشرط الذي يراقبه النظام.
- **المستويات (Levels):** قائمة بالأهداف (Targets) والمكافآت لكل مستوى.

## كيف يتم إنشاء وسام؟
يتم إنشاء الأوسمة عبر نظام "الحقن العصبي" (Neural Injection) باستخدام صيغة JSON.

### مثال بسيط لوسام:
```json
{
  "badges": [
    {
      "id": "badge_level_10",
      "name": "The Rising Star",
      "icon": "⭐",
      "category": "progression",
      "triggerType": "metric",
      "metricKey": "level",
      "levels": [
        { "tier": "silver", "target": 10, "quote": "The journey begins.", "rewards": { "xp": 100, "gold": 50 } },
        { "tier": "gold", "target": 20, "quote": "You are shining.", "rewards": { "xp": 500, "gold": 200 } }
      ]
    }
  ]
}
```

## المكافآت (Rewards)
عند فتح أي مستوى من مستويات الوسام، تحصل فوراً على:
- **نقاط خبرة (XP):** تساهم في رفع مستواك العام.
- **ذهب (Gold):** يمكنك استخدامه في المتجر.
- **اقتباس (Quote):** رسالة تشجيعية تظهر في نافذة الاحتفال.
