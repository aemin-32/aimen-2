# دليل الغارات (Raids) - الجزء الثاني: Zayn2 🛡️

هذا الدليل مخصص لشرح نظام الغارات في تطبيق Ascension، وهو الجزء الثاني من سلسلة مكونة من 4 أجزاء.

## ما هي الغارات (Raids)؟
الغارات هي مشاريع كبيرة أو "عمليات" تتكون من عدة خطوات (Missions) متسلسلة. تهدف الغارات إلى تنظيم الأهداف المعقدة التي تتطلب أكثر من مهمة واحدة لإنجازها.

## مميزات نظام الغارات
1. **التسلسل المنطقي:** يتم قفل الخطوات تلقائياً بحيث لا يمكنك البدء بالخطوة التالية إلا بعد إنهاء الحالية.
2. **ربط المهارات:** يمكنك ربط الغارة بمهارة معينة (Skill) لزيادة نقاط الخبرة (XP) فيها عند الإنجاز.
3. **نظام المكافآت:** عند إنهاء الغارة بالكامل، تحصل على مكافأة ضخمة (Loot) تشمل الذهب ونقاط الخبرة.
4. **الحقن الذكي (Smart Append):** يمكنك إضافة خطوات جديدة لغارة موجودة مسبقاً بمجرد استخدام نفس العنوان.

## كيفية إنشاء غارة عبر الحقن (Injection)
يمكنك استخدام الذكاء الاصطناعي لتوليد غارات بصيغة JSON وحقنها في النظام.

### الهيكل الأساسي للحقن:
```json
{
  "raids": [
    {
      "title": "اسم العملية (مثلاً: Operation: Apollo)",
      "description": "وصف تكتيكي للغارة",
      "difficulty": "hard",
      "stats": ["INT", "STR"],
      "steps": [
        { "title": "الخطوة الأولى: الاستطلاع" },
        { "title": "الخطوة الثانية: التنفيذ" }
      ]
    }
  ]
}
```

## ميزة الإضافة الذكية (Smart Append)
إذا كانت الغارة طويلة جداً، يمكنك حقنها على أجزاء:
1. **الجزء الأول:** احقن الغارة مع أول خطوتين.
2. **الجزء الثاني:** احقن نفس الغارة بنفس العنوان (`title`) مع خطوات جديدة.
3. **النتيجة:** سيقوم النظام تلقائياً بإضافة الخطوات الجديدة إلى نهاية الغارة الموجودة ولن يكرر إنشاء الغارة.

## نظام القفل الذكي
- الخطوة الأولى في أي حقنة جديدة ستكون **مفتوحة** فقط إذا كانت آخر خطوة في الجزء السابق **مكتملة**.
- إذا لم تكن قد أنهيت الجزء السابق، ستبقى الخطوات الجديدة **مقفلة** حتى تصل إليها بالتسلسل.

## نصائح للمحترفين
- استخدم أسماء عسكرية للغارات لتعزيز تجربة الـ RPG (مثلاً: *Operation: Midnight Code*).
- حدد صعوبة الغارة بناءً على الجهد المطلوب؛ الغارات الصعبة تعطي مكافآت أكبر بكثير.
- لا تنسَ ربط الغارة بمهارة (Skill ID) لضمان تطور مستواك في تلك المهارة.
